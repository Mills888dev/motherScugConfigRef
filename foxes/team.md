# Corn: pheromones and the pack

| Setting | Default | Unit | What it does |
|---|---|---|---|
| `pheromone_enabled` | `false` |  |  |
| `pheromone_share` | `"all"` |  | What gets shared with packmates. Options: all, prey, threats. |
| `pheromone_range_tiles` | `0.0` | tiles | How far away a packmate can be and still share. 0 or less: no limit. |
| `flank_enabled` | `false` |  | Enables pack flanking, where the pack splits up to surround the target. |
| `flank_block_enabled` | `false` |  | Enables followers blocking the target's ways out. |
| `flank_herd_enabled` | `false` |  | Enables the pack herding the target into a dead end. |
| `flank_sync_enabled` | `false` |  | On: blockers wait and all attack together. Off: each attacks on arrival. Needs flank_block_enabled. |
