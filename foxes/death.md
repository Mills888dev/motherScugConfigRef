# Stun, blindness and death

| Setting | Default | Unit | What it does |
|---|---|---|---|
| `blind_enabled` | `true` |  |  |
| `blind_stun_enabled` | `true` |  | Enables a stun from a flashbang. |
| `death_throes_enabled` | `true` |  | Enables twitching after death. |
