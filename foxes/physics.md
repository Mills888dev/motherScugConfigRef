# Body physics and swimming

| Setting | Default | Unit | What it does |
|---|---|---|---|
| `body_mass` | `3.2` |  | Total physics mass, split evenly across the three body chunks. |
| `body_size_fac` | `0.9` |  | Overall body scale. |
| `body_rad_fac` | `1.0` |  | Scales the collision radius of the body chunks only. |
| `body_length_fac` | `1.0` |  |  |
| `swim_speed` | `0.2` |  | Sideways paddle force while swimming. |
