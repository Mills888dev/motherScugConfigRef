# Ledges, pipes and tight spaces

| Setting | Default | Unit | What it does |
|---|---|---|---|
| `ledge_pounce_enabled` | `true` |  | Enables the ledge leap when not hunting. Needs pounce_enabled. |
| `ledge_pounce_max_rise` | `95.0` | px | The tallest ledge a leap attempts. |
| `ledge_pounce_max_drop` | `120.0` | px | The deepest drop a descending leap may aim at. |
| `reach_enabled` | `true` |  | Enables the fox to use pounce for navigation. |
